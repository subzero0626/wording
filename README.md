# LETTERS — 살아있는 글자 보드

보드 위를 돌아다니는 알파벳을 직접 끌어다 붙여 단어를 만들고,
만들어진 단어가 **자기 뜻대로 행동하는** 하나의 긴 방치형 세션.

스테이지도, 라운드도, 정산도 없다. 보드 하나가 계속 자란다.

## 재화

모든 오브젝트는 **20초마다 한 번** 벌어들인다.

| | 한 번에 버는 양 |
|---|---|
| 낱글자 | 1 |
| 아직 단어가 아닌 덩어리 | 글자 수 × 1 |
| 사전에 있는 보통 단어 | `4 × 2 ^ (글자수 - 3)` |
| 능력 단어 50개 | 위와 같다 |
| 보석을 SHOP 에 넘길 때 | `250 × 글자수 × 품질(1 ~ 1.5)` |

| 글자수 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|
| 단어 | **4** | **8** | **16** | **32** | **64** | **128** |
| 그냥 낱글자로 두면 | 3 | 4 | 5 | 6 | 7 | 8 |

능력 단어도 보통 단어와 똑같이 글자 수로만 벌이가 정해진다.
능력은 벌이가 아니라 행동으로 드러낸다. 다만 상황에 따른 보너스는 그대로다
(GOLD 는 BANK 곁에서, FISH 는 물가에서 더 번다).

단어로 만들기만 해도 이득이고, 길수록 격차가 폭발적으로 벌어진다.
**긴 단어를 만드는 것이 곧 성장**이다. 자리도 훨씬 덜 차지한다.

조정하려면 `js/data.js` 의 `PAY_WORD_BASE`(3글자 기본값)와 `PAY_GROWTH`(글자당 배수) 두 개만 바꾸면 된다.

## 사전

영어 단어 **65,014개**(3~8글자)가 게임에 들어 있다.
사전에 있는 단어라면 무엇이든 만들 수 있고 전부 재화를 번다.
그중 50개만 특별한 능력을 가진다.

- 표제어 출처: [ENABLE word list](https://norvig.com/ngrams/enable1.txt) (public domain)
- **순수 소문자 알파벳 단어만** — 고유명사·약어·숫자 섞인 문자열은 전부 제외.
- **2글자 단어 제외** — 두 글자가 곧바로 단어로 굳어 버리면 긴 단어를 못 만든다.
- **뜻이 확인된 단어만 채택** — 그래서 만든 단어는 언제나 뜻을 볼 수 있다.
- `js/dict.js` 에 길이별 고정폭 문자열로 들어 있다 (427KB). 네트워크 연결이 필요 없다.
- 붙이려고 글자를 가져가면 **완성될 단어와 벌이가 미리 표시**된다.

### 단어 키우기

이미 완성된 단어에 글자를 더 붙여 더 긴 단어로 키울 수 있다 (`CAT` → `CATS`).

한 번에 완성되지 않아도 된다. **더 붙이면 단어가 될 조각**이면 도중 상태로 놔둘 수 있다 —
`MOTH` 에 `E` 를 붙여 `MOTHE` 로 두었다가, `R` 을 마저 붙여 `MOTHER` 로 키우는 식이다.
이때 조각 위에 `MOTHE…` 라고 흐리게 떠서 "이 방향에 단어가 있다" 는 것을 알려 준다.

반대로 `MOTHQ` 처럼 어떤 단어로도 이어지지 않는 조각은 아예 붙지 않는다.
애써 만든 단어가 아무 데도 못 가는 덩어리로 망가지는 일은 없다.
잘못 붙였더라도 덩어리를 더블클릭하면 낱글자로 되돌아온다.

판정은 `G.canGrow()` 가 한다. 사전이 길이별 고정폭 문자열이라, 조각이 나타난 위치가
칸 경계에 맞는지만 보면 그 단어의 머리인지 꼬리인지 바로 알 수 있다.

### 낱글자 분포

모음 5개가 합쳐서 **30%**, 자음 21개가 나머지 70% 를 **영어에서 쓰이는 빈도대로** 나눠 갖는다.
자음까지 균등하게 뿌리면 Q·X·Z·J 가 T·S·R 만큼 자주 나와 보드에 쓰레기만 쌓인다.

## 단어 뜻 (더블클릭)

단어를 더블클릭하면 **품사 · 한글 뜻 · 영어 뜻**이 뜬다. 어형변화라면 원형도 알려준다.

```
CATS   명사
CAT 의 변화형
고양이
feline mammal usually having thick soft fur and no ability to roar
20초마다 8w                                              [분해]
```

- 영어 뜻: [WordNet 3.1](https://wordnet.princeton.edu/) (Princeton) + Webster's 1913 (public domain)
  — 사전에 있는 **모든 단어**에 있다.
- 한글 뜻: [kengdic](https://github.com/garfieldnate/kengdic) 한영사전을 영→한으로 뒤집은 것
  — **약 66%** 의 단어에 있다. 없으면 영어 뜻만 나온다.
  능력 단어는 직접 확인해 지정했다 (`scratchpad/ko-build.js` 의 `OVERRIDE`).
- 뜻 데이터는 4.6MB라 한꺼번에 들고 있지 않고, **첫 글자 파일(`js/defs/A.js` … `Z.js`)만 그때그때** 불러온다.
- `fetch` 가 아니라 `<script>` 태그로 불러오므로 `file://` 로 열어도 동작한다.

능력 단어가 무슨 일을 하는지는 **도감** 쪽에 적혀 있다. 더블클릭 팝오버는 사전 역할만 한다.

### 한글 뜻 손질 (`G.defs.koText`)

뒤집어서 만든 데이터라 그대로 쓰면 지저분하다. 보여주기 전에 두 가지를 한다.

**조각 걸러내기.** 표제어에서 떨어져 나온 파편이 후보에 섞여 있다.
`에게 잔소리하다` · `구균의 뜻` · `체강의 뜻` 처럼 조사로 시작하거나 "…의 뜻" 으로
끝나는 것을 버리고, 품사에 맞는 후보를 앞세워 **둘까지만** 보여 준다.
`형사, 포박하다, 로야단맞다` → `형사, 포박하다`.
한 글자짜리(`불` · `물` · `쥐`)는 가장 흔한 뜻인 경우가 많으므로 남긴다.

**변화형 활용.** 어형변화형은 원형의 뜻을 그대로 물려받아서 `ACTED` 에도
`출연하다` 가 뜬다. 이걸 그 모양에 맞게 바꾼다.

| 꼴 | 예 |
|---|---|
| `-ED` | ACTED · 출연하다 → **출연한** / WALKED · 걷다 → **걷던** |
| `-ING` | ADDING · 가하다 → **가하고 있는** |
| `-LY` | 걷다 → **걷게** |
| `-S` | CATS · 고양이 → **고양이들** |

한국어는 어간마다 활용이 달라서 `-ED` 를 억지로 "은" 으로 만들면 틀린 말이 나온다
(걷다 → 걷은 ✗). "하다" 로 끝날 때만 "한" 을 붙이고, 그 밖에는 어떤 어간에나
그대로 붙는 "던" 을 쓴다.

"들" 은 이름씨 꼴로 끝나는 후보에만 붙인다. `RUNS` 의 뜻은 `달리다` 라 그대로 둔다.

원형이 기록된 단어에서만 바꾼다. `SEED` · `FEED` 처럼 원래 `-ED` 로,
`GLASS` · `NEWS` 처럼 원래 `-S` 로 끝나는 단어까지 변화형으로 읽어 버리면 안 되기 때문이다.

## 실행

`index.html` 을 브라우저로 그냥 열면 된다. 빌드도 설치도 없다.

간단한 서버로 띄우고 싶다면:

```
cd C:\test
python -m http.server 8765
# http://127.0.0.1:8765
```

진행 상황은 localStorage 에 자동 저장된다 (약 6초마다 + 탭을 떠날 때).

보드는 두 경우에 통째로 잠든다 — **글자도 생기지 않고** 단어도 움직이지 않는다.

- 탭을 떠나거나 창이 가려졌을 때
- 페이지를 켜 둔 채로 **5분 동안 아무 조작이 없을 때** (`IDLE_AFTER`)

뒤쪽은 화면을 옅게 덮어 잠들었다는 것을 알려 주고, 마우스를 움직이거나
아무 곳이나 누르면 곧바로 깨어난다.

잠들어 있던 동안 **벌었을 액수의 10%** 를 깨어날 때 받는다 (최대 2시간까지 인정).
켜 두고 들여다보는 쪽이 언제나 이득이다.

## 첫 판

낱글자 8개로 시작하며 `C A T R E S O N` 이 정해져 나온다 —
CAT · RAT · CARE · STORE · SNORE · CRATE · ACTORS 처럼 여러 갈래가 바로 열린다.
무작위로 뿌리면 자음만 잔뜩 나와 한 단어도 못 만들고 기다리게 되기 때문이다.

생성 간격 자체는 손대지 않는다 (45초 → 18초, 업그레이드로만 줄어든다).
한때 "보드가 한산하면 글자가 빨리 온다" 는 가속을 넣었다가 뺐다 —
초반은 확실히 나아지지만 게임 전체가 너무 빨라졌다.

## 사건 보상

DOG 이 파낸 것, CAR 의 배달, LUCK 의 횡재처럼 **한 번씩 터지는 수입**은
평생 벌어들인 총액이 아니라 **지금 보드가 20초에 버는 양(`payRate`)** 을 기준으로 계산한다
(`behaviors.js` 의 `reward(배수, 최소분)`).

총액에 비례시키면 벌수록 사건이 커지고 그래서 더 벌게 되는 눈덩이가 만들어져,
후반에는 단어를 만드는 것보다 개 한 마리를 두는 쪽이 이득이 되어 버린다.
지금 보드를 기준으로 잡으면 보상은 언제나 "몇 초치 수입"으로 읽히고,
보드를 잘 꾸릴수록 사건도 같이 커진다.

## 단어는 자기 뜻대로 행동한다

이 게임을 붙잡는 것은 수치가 아니라 **글자끼리의 상호작용**이다.
그래서 좋기만 한 단어도, 나쁘기만 한 단어도 두지 않는다.
단어는 자기 뜻대로 굴고, 그게 이득이 될지 손해가 될지는 **어디에 놓느냐**가 정한다.

FIRE 는 집을 태운다. 동시에 MEAT 를 굽고 SAND 를 녹이고 GOLD 를 제련한다.
BUG 는 나무를 갉지만 BIRD 에게는 먹이다.
MOUSE 는 돈을 축내지만 CHEESE 로 길들이면 벌어 온다.
GHOST 는 옆 단어를 놀래키지만, 겹쳐 세우면 씌어서 벌이를 부풀린다.

### 변환 사슬

재료를 만들어 조건에 맞게 놓고 기다리면 다른 단어가 된다 (`bonds` 의 `key:'cook'`).

| 재료 | 곁에 둘 것 | 결과 |
|---|---|---|
| MEAT | FIRE | ROAST |
| SAND | FIRE | GLASS |
| ICE | FIRE | WATER |
| WATER | FIRE (아주 오래) | STEAM → 식으면 다시 WATER |
| ROCK | RIVER | SAND |
| MILK | TIME | CHEESE |
| TREE | 다 타고 나면 | COAL |
| SEED | 시간 (물·볕이면 빨리) | TREE |
| EGG | 시간 (TIME 이면 빨리) | BIRD |

COAL 은 다시 FIRE 를 거세게 만들고, 거센 불은 모든 조리를 두 배로 빨리 끝낸다.
GLASS 는 SUN 과 짝지으면 렌즈가 되어 초점에 불을 붙인다 — FIRE 없이 불을 얻는 길이다.

### 손을 대야 하는 것

방치형이지만, 보고 있으면 더 벌 수 있는 자리를 남겨 뒀다.

- **굽기** — MEAT 가 ROAST 로 바뀌면 한동안 두 배 반을 번다. 그대로 두면 연기가 점점 짙어지다가
  타 버리고, 불에서 빼내도 식으면서 값이 떨어져 결국 MEAT 로 돌아간다.
  남은 시간을 숫자로 세어 주지 않는다 — 연기가 시계다.
- **보석 팔기** — GOLD · IRON · RUBY · EMERALD · DIAMOND 를 만들어 SHOP 위에 1초쯤 올려 두면
  `250 × 글자 수 × 품질` 만큼 목돈이 된다. 품질은 단어를 만든 순간 1 ~ 1.5 사이에서 정해지고,
  숫자로 알려 주는 대신 좋은 것일수록 자주 반짝인다. 어울리는 짝을 곁에 두면 값이 더 오른다
  (GOLD+BANK, RUBY·IRON+FIRE, EMERALD+TREE, DIAMOND+LAMP·SUN).
- **불 관리** — 불은 가연성 단어로 계속 옮아붙는다. WATER 를 끌어다 대거나,
  ROCK 으로 벽을 세워 길을 끊거나, TIME 을 옆에 두어 번지는 속도를 늦춰야 한다.
- **천적 떼어놓기** — CAT 은 MOUSE 를 쫓고 BIRD 는 BUG 를 쫓는다.
  쥐로 치즈를 갉게 하려면 고양이를 멀리 둬야 한다.

### 보석

GOLD · IRON · RUBY · EMERALD · DIAMOND 는 만들어지는 순간 **품질**이 1 ~ 1.5 사이에서
한 번 뽑히고 그 뒤로 바뀌지 않는다. 품질은 20초마다 버는 돈에도, SHOP 매입가에도 그대로 곱해진다.
보석은 가만히 두면 조금씩 벌지만, 진짜 값은 SHOP 에 넘길 때 나온다.

보석마다 어울리는 짝이 있고 그 곁에서는 값이 1.5배가 된다.
GOLD 는 BANK, RUBY 와 IRON 은 FIRE, EMERALD 는 TREE 와 SEED, DIAMOND 는 LAMP 와 SUN.
DIAMOND 는 빛을 받으면 곁에 있는 것들까지 잘 벌게 하고, IRON 은 불에 달아오르면 주변을 데운다.

### 배수는 크게 잡지 않는다

한 자리에서 나오는 배수는 대체로 **2.5배 안쪽**으로 둔다.
일곱 배, 열 배짜리가 하나 생기면 그 뒤로는 그 하나만 굴리는 게임이 되고,
나머지 마흔아홉 단어를 굳이 써 볼 이유가 사라진다.
이 게임에서 커져야 하는 것은 한 단어의 배수가 아니라 **얽히는 가짓수**다.

## 힌트 값

도감 힌트는 1단계 60w, 2단계 260w 에서 시작해 **지금까지 산 힌트 개수만큼 비싸진다**
(한 개당 ×1.05, 최대 9배). 초반에는 막힌 곳을 부담 없이 뚫어 주고,
후반에는 남아도는 재화가 조금씩 빠져나가는 자리가 된다.

```
  defs.js        단어 뜻 지연 로더
  defs/A..Z.js   첫 글자별 뜻 데이터 (생성물, 필요할 때만 로드)
  data.js        밸런스 상수 + 능력 단어 50개   ← 단어 추가는 여기서만
  fx.js          캔버스 파티클 레이어
  entity.js      보드 오브젝트 (낱글자 / 클러스터 / 단어)
  board.js       오브젝트 목록, 놀이영역/확장, 충돌 분리, 수입
  drag.js        드래그 · 스냅 · 조합 판정
  behaviors.js   FIELDS / ACTIONS / BONDS + 접촉 타이머
  ui.js          게이지 · 재화 · 도감 · 팝오버 · 일시정지
  save.js        자동 저장
  game.js        메인 루프
```

ES 모듈을 쓰지 않는다 (`file://` 로 바로 열 수 있게 하려고). 전역 `G` 네임스페이스 사용.

## 새 단어 추가하기

`js/data.js` 의 `G.WORDS` 에 항목 하나를 넣으면 끝이다.

```js
{
  id: 'CANDLE', kind: '사물', tags: ['metal'],
  desc: '도감과 단어 설명 팝오버에 그대로 쓰인다.',
  hint: '힌트 2단계에서 보여줄 짧은 설명',
  color: { fg:'#8a6a2c', bg:'#fffaf0', bd:'#e0cb96' },
  anim: 'pulse',        // shake | wave | float | pulse | tick | hop | still
  fx:   'sparkle',      // fx.js 의 AMB 키 (상시 파티클), 없으면 null
  motion: { min:20, max:35, range:60 },   // 점프 간격(초)과 반경. null 이면 안 움직임
  heavy: false, ghost: false,
  act: 'candleAct', actEvery: [20, 30],   // behaviors.js 의 ACTIONS[key]
  bonds: [{ with:['BOOK'], range:110, time:8, key:'read' }]  // BONDS[key]
}
```

새 단어는 **그 단어의 뜻대로** 행동해야 한다. 이롭기만 하거나 해롭기만 한 능력은
넣지 않는다. 해가 되는 성질을 준다면 그것을 살려 쓰는 길을 반드시 같이 낸다
(FIRE 는 태우지만 굽고, BUG 는 갉지만 BIRD 의 먹이다).
게임에 없던 요소를 만들어도 되지만, 그럴 때는 보석 품질처럼 여러 단계를 거쳐야
값이 나오게 두어서 거저 얻지 못하게 한다.

도감 설명에는 **정확한 수치를 쓰지 않는다**. "20초쯤 머무르면" 이 아니라
"한참 붙어 있으면", "5초 있으면" 이 아니라 "잠깐만 있어도" 라고 적는다.
숫자는 코드에 있고, 도감은 그 단어가 어떤 성격인지만 알려 주는 자리다.

- **FIELDS[단어id]** — 매 프레임 지속되는 장(場) 효과 (끌어당김, 밝힘, 가속…)
- **ACTIONS[key]** — `actEvery` 주기로 한 번씩 터지는 사건
- **BONDS[key]** — "가까이 + 일정 시간" 이 유지돼야 발동. 떨어지면 타이머는 즉시 리셋된다.

`with` 에는 단어 id 배열, `'#태그'`, `'@letter'`, `'*'` 를 쓸 수 있다.
